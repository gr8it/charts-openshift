# Changelog

All notable changes to this component will be documented in this file.

The format is based on [Common Changelog](https://common-changelog.org/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-11-19

### Changed

- **Breaking:** requires Kyverno >= 1.20; legacy `ClusterPolicy`/`ClusterCleanupPolicy` migrated to CEL policies (`policies.kyverno.io/v1`)
- `app-project-eso-vault` → `GeneratingPolicy` for the synchronized SecretStore and auth-delegator ClusterRoleBinding (name kept, existing resources are adopted)
- `vault-auth` ServiceAccount and AuthBackendRole moved to `app-project-eso-vault-sa` and `app-project-eso-vault-auth-backend-role`, created only when missing
- `policy-svc-vie` → `GeneratingPolicy` (server-side apply), generated once the Backend reports its accessor
- `app-project-eso-vault-cleanup` → `DeletingPolicy`, also cleans up AuthBackendRoles generated by the pre-1.20 policy
- background controller can get/list/watch SecretStores, ClusterRoleBindings and vault Policies (Kyverno >= 1.20 watches synchronized downstream resources)
