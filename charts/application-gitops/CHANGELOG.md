# Changelog

All notable changes to this component will be documented in this file.

The format is based on [Common Changelog](https://common-changelog.org/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-11-19

### Changed

- **Breaking:** requires Kyverno >= 1.19, `ClusterPolicy` migrated to CEL
- AppProject and RoleBinding are generated by the synchronized `GeneratingPolicy` `<fullname>` (name kept, existing resources are adopted); it now also processes Application UPDATEs, as skipping them would delete the synchronized downstream resources
- ServiceAccount moved to `<fullname>-serviceaccount`, created only when missing
- **Breaking:** role `policies` values use the Kyverno CEL placeholder `(( object.metadata.namespace ))` instead of `{{ request.object.metadata.namespace }}`; overrides in `roleEnvOverrides`/`roleClusterOverrides` must be updated
- background controller can list/watch AppProjects (Kyverno >= 1.19 watches synchronized downstream resources)

_([SPEXAPC-32527](https://aspecta.atlassian.net/browse/SPEXAPC-32527))_
