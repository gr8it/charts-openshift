# Changelog

All notable changes to this component will be documented in this file.

## [1.2.4] - 2026-11-12

### Changed

- Remove the default AppProject sync-wave annotation.
- Application sync options override defaults with the same option name.

## [1.2.3] - 2026-11-11

### Changed

- Only render AppProject annotations when provided; no default sync-wave is added.

## [1.2.2] - 2026-11-10

### Changed

- Default AppProjects to sync wave `-1` so they are created before Applications.
